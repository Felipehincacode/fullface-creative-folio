🎬 README – Reel “Razones” | Full Face Academy

Video creado para poner a prueba al público y recordar por qué vale la pena estudiar.
Grabado con iPhone 11 y luces LED, con algunos planos generados por IA.
Voz mejorada con ElevenLabs y edición realizada en CapCut PC, usando Higsfield para transiciones IA.
Duración: 30s.
Se redujo el número de razones para mantener ritmo y claridad; a futuro podría regrabarse el primer plano o crear una versión extendida.
La pieza busca inspirar superación y reforzar el posicionamiento académico de Full Face Academy.
